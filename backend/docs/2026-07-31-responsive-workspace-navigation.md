# 2026-07-31 Responsive Workspace Navigation

## Change

- Desktop keeps the existing top workspace tabs.
- Small screens now move workspace tabs into a persistent left navigation rail.
- Mobile rail includes:
  - Dashboard
  - Clients
  - Campaigns
  - Content
  - Workflow
  - Team
- Active workspace section is highlighted in both desktop and mobile navigation.
- Workspace content and footer now reserve left space on small screens so the rail does not cover the page.

## Product Reason

The top header should stay light on small screens. The main workspace sections remain always available without wrapping, crowding, or pushing the profile menu.
