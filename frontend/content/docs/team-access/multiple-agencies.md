## What This Means

One AGENCIE account can belong to more than one agency.

You do not need to create a separate account or use a different email address for every agency you work with.

Each agency membership is handled separately.

## Example

An editor could work with two different agencies using the same AGENCIE account.

For example:

SocialExpert
→ Editor

Another Agency
→ Editor + Designer

The person's account is the same, but their role and access can be different in each workspace.

## Agency-Specific Membership

Your membership belongs to a specific agency.

Each membership determines things such as:

- Roles
- Permissions
- Workspace access
- Client access where applicable

A role in one agency does not automatically apply to another agency.

For example, being a Manager in Agency A does not make you a Manager in Agency B.

## Switching Workspaces

When you switch to another agency, AGENCIE changes the active workspace.

The active agency determines which:

- Clients
- Campaigns
- Gigs
- Team members
- Workflow
- My Work
- Calendar
- Publishing schedules

you can access.

## Work Is Kept Separate

Operational data belongs to the agency where it was created.

Agency A
→ Clients, campaigns, team and work belonging to Agency A

Agency B
→ Clients, campaigns, team and work belonging to Agency B

Switching agencies changes the workspace context. It does not combine work from different agencies into one shared workspace.

## Invitations To Another Agency

If you already have an AGENCIE account and another agency invites the same email address, you do not need to create another account.

Accept the invitation using your existing account.

AGENCIE adds a separate membership for the new agency.

## Roles Can Be Different

The same person can have completely different responsibilities across agencies.

For example:

Agency A
→ Writer

Agency B
→ Social Media Manager

Agency C
→ Manager

Navigation and available actions change according to the roles associated with the currently active agency.

## Security Boundary

AGENCIE is multi-tenant.

Access to one agency does not grant access to another agency's data.

Directly opening a URL belonging to another agency does not bypass the membership and access checks for that workspace.

> [!IMPORTANT] Check Your Active Workspace
> Before creating clients, campaigns, gigs, or assigning work, make sure you are inside the correct agency. The data you create belongs to the active agency workspace.
