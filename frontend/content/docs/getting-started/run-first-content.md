## Best First Test

Create one client, one campaign, one publishing slot, then generate production from that slot.

## Flow

1. Create a campaign for the client.
2. Add a publishing slot.
3. Generate production from the slot.
4. AGOS creates a content asset and workflow.
5. The writer receives the first task.
6. The work moves through review, shoot, editor intake, editing, review, and publishing readiness.

## What Happens Next

Every stage appears in Workflow. Deadlines appear in Calendar. Direct assignments appear in My Work.

> [!WARNING] Do Not Use A Campaign For Every Tiny Request
> If you only need 5 scripts by Friday, create a Gig instead. It is faster and does not require a full campaign plan.
