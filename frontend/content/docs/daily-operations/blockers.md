## When To Use A Blocker

Use a blocker when the current owner cannot move the work forward.

Examples:

- Waiting for client assets
- Missing footage
- Need clarification
- Talent unavailable
- Approval stuck

## What Happens Next

The item becomes visible as blocked in workflow metrics. Managers and owners can see what needs help without asking for updates in chat.

## Good Blocker Notes

Write the reason clearly. A blocker should explain what is needed, not only that work is delayed.
