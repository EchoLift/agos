## What This Is

Reviews are where managers and owners decide whether work should move forward or return to the previous person.

## Script Review

When a writer submits work, the manager can approve it or request changes.

Approve moves the content toward shoot. Request changes sends it back to the writer.

## Editor Intake

When DOP footage is handed over, the editor can accept or reject the handover.

Rejecting handover sends it back to the DOP with a reason.

## Edit Review

When the editor submits a draft or final link, the manager can approve or request changes.

Approval can make the content ready for publishing.
