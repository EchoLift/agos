## What It Is

Workflow is the production board. It shows content moving through writing, review, shoot, editor intake, editing, manager review, and publishing readiness.

## Role Views

Owners and managers can see broader production. Production roles see their own tasks and relevant work.

## Common Stages

- Writing
- Manager Script Review
- Shoot
- Editor Intake
- Editing
- Manager Edit Review
- Client Approval
- Published

## What Happens Next

Open a card to see the current owner, deadline, client vibe, campaign context, and available actions.

> [!IMPORTANT] Source Of Truth
> Workflow is the main production truth. Calendar and My Work are projections of workflow tasks and gig assignments.
