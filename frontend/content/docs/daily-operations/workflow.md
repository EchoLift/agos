## What It Is

Workflow is AGENCIE's production board.

It shows where content currently is in the production process, who owns the current work, and what needs to happen before it can move forward.

Instead of tracking production through scattered messages, Workflow keeps the current state connected to the content itself.

## How Work Moves

A workflow can move content through stages such as:

Writing
→ Review
→ Shoot
→ Editor Intake
→ Editing
→ Review
→ Approval
→ Ready for Publishing

The exact stages depend on the workflow configured for the content.

## Role Views

Owners and managers can see broader production activity available to them.

Production team members see workflow information relevant to their role, assignments, and workspace access.

Being able to view a workflow does not automatically allow a user to perform every workflow action.

## Common Stages

Depending on the configured workflow, stages can include:

- Writing
- Script Review
- Shoot
- Editor Intake
- Editing
- Edit Review
- Approval
- Ready for Publishing
- Published

Workflow names and stages may vary depending on how the production process is configured.

## Task Ownership

Each active production task can have an owner responsible for moving the work forward.

Role
→ Defines what kind of work a person can perform

Campaign Team
→ Defines who is involved in the campaign

Workflow Task
→ Defines who currently owns a specific production action

This distinction keeps production responsibility clear.

## Working With A Workflow

Open a workflow item to see relevant production context such as:

- Current stage
- Current owner
- Deadline
- Campaign
- Client context
- Content details
- Previous production activity
- Available actions

The actions shown depend on the current workflow stage and your permissions.

## Reviews And Handovers

Some workflow stages require another person to review or accept work before production continues.

Examples include:

- Writer submits a script for review
- Reviewer approves or requests changes
- DOP hands footage to the editor
- Editor accepts or rejects the handover
- Editor submits completed work for review
- Reviewer approves or requests changes

These actions move the underlying workflow rather than simply changing a visual status.

## Blockers

When work cannot continue because something is missing or unresolved, it can be marked as blocked where supported.

The blocker should explain what is preventing progress and what needs to happen before production can continue.

## What Happens Next

Completing an available workflow action moves the content into its next configured stage.

The next task, owner, or review step depends on the workflow definition and production state.

AGENCIE keeps this progression connected to the content so the team can see both what has happened and what needs to happen next.

> [!IMPORTANT] Source Of Truth
> Workflow is the primary source of truth for production state and task ownership. My Work and Calendar provide focused views of work derived from workflow tasks, assignments, schedules, and gigs.
