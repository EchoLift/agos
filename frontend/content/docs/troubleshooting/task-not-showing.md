## Start With Assignment

Having a role is not the same as being assigned work.

For example:

Editor
→ You are allowed to perform editing work.

Assigned Editor
→ This specific editing task belongs to you.

My Work primarily follows actual responsibility, not every task associated with your role.

## Check The Active Workspace

Make sure you are inside the correct agency.

Work is scoped to the agency where it was created.

If you belong to multiple agencies, switching workspaces changes the tasks, Gigs, campaigns, workflows, and calendar activity available to you.

## Check The Task Owner

For workflow work, check who currently owns the active task.

A content item may belong to a campaign you are involved with while its current production task belongs to someone else.

For example:

Writing
→ Writer owns the task

Script Review
→ Reviewer owns the task

Shoot
→ DOP owns the task

The content still exists throughout the process, but personal responsibility changes as the workflow moves forward.

## Check Gig Assignment

For a Gig, verify that the correct person is selected as the assignee.

Having the appropriate role does not automatically make the Gig appear as your assigned work.

If the Gig has moved to review, responsibility may also have moved from the assignee to the reviewer.

## Check The Current State

Completed or transitioned work may no longer appear in the same active-work view.

Check whether the task or Gig has already been:

- Submitted
- Approved
- Completed
- Returned
- Reassigned
- Moved to another workflow stage

When a workflow moves forward, a new task or owner may become responsible for the next action.

## Check My Work

My Work is your personal work queue.

If something is missing, verify that:

- You are the current assignee or task owner.
- The work is still active.
- You are in the correct agency.
- The work has not moved to another person for review or another production stage.

## Check Calendar

Calendar is a time view rather than a complete list of everything you can access.

If work appears in My Work or Workflow but not Calendar, check:

- Due date
- Scheduled date
- Calendar scope
- Visible calendar groups
- Current assignment

Work without a relevant date may not have anything meaningful to display on Calendar.

## Check Calendar Scope

Use **My Schedule** when you want work directly relevant to you.

Broader scopes may show additional work depending on your role and permissions.

If you expected a task because of your role rather than direct assignment, check whether the selected Calendar scope includes that role-based work.

## Check Workflow

If you still cannot find the expected task, open the related content in **Workflow**.

Workflow is the primary source of truth for production state and current task ownership.

Check:

1. Current workflow stage
2. Current task
3. Current owner
4. Assignment
5. Deadline
6. Whether the task has already transitioned

## After A Recent Change

If work was just assigned, created, submitted, or transitioned, AGENCIE should refresh the relevant workspace data automatically.

You should not normally need to reload the browser manually.

If the backend shows the correct assignment but the interface continues showing older data after the refresh completes, treat that as a stale-data issue rather than changing roles or assignments to work around it.

> [!IMPORTANT] Role Is Not Ownership
> Roles determine what kind of work a person can perform. Assignments determine which specific work they are responsible for. When something is missing from My Work, check the current owner before changing permissions.
