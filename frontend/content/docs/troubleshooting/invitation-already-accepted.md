## What It Means

An invitation can only be accepted while it is valid and pending.

If AGENCIE reports that an invitation has already been accepted, the invitation may already be connected to an active agency membership.

The person may therefore already exist in **Team**.

## What To Do

Open **Team** and search for the person using their name or email address.

If they are already an active member, do not send another invitation just to change their access.

Authorized users can update the existing member's roles instead.

## Changing An Existing Member's Roles

If the person already belongs to the agency:

1. Open **Team**.
2. Find the member.
3. Choose **Edit roles** if your role allows it.
4. Add or remove the required roles.
5. Save the changes.

Updating an existing member does not create another membership or send another invitation.

## Re-Inviting A Removed Member

If someone previously accepted an invitation but was later removed from the agency, they may need a new invitation before joining again.

Create a new invitation using their email address.

The new invitation has its own lifecycle and should appear as **Pending** until it is accepted.

A previously accepted invitation does not make a newly created invitation accepted.

## Other Invitation States

An invitation may also be unavailable because it is:

- **Accepted** — The invitation has already been used.
- **Cancelled** — An authorized user cancelled the invitation.
- **Expired** — The invitation was not accepted before its expiry time.
- **Declined** — The recipient declined the invitation.

When appropriate, create a new invitation rather than trying to reuse an invitation that is no longer pending.

## Wrong Email Address

Invitations are associated with the email address they were created for.

If the invitation was sent to the wrong email address:

1. Cancel the incorrect pending invitation where possible.
2. Create a new invitation using the correct email address.
3. Ask the recipient to sign in using that email when accepting the invitation.

## CLIENT Invitations

If the invitation is for a CLIENT user, also verify that the correct business client was selected.

The resulting CLIENT membership is scoped to that business client.

If the person is already an active member and needs their CLIENT role changed, authorized users should edit the existing membership instead of creating another invitation.

> [!TIP] Check Team First
> Before re-inviting someone, search for them in Team. If they are already an active member, update their existing access instead of creating another invitation.
