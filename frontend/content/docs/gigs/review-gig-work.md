## Who Can Review

The selected reviewer, owner, or manager can review gig work.

## Review Options

- Approve
- Request changes

## What Happens Next

Approve completes the gig. Request changes returns it to the assignee with feedback.

## Good Feedback

Write exactly what should change. The goal is to avoid another follow-up conversation outside AGOS.
