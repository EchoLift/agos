## What It Is

When you finish work assigned through a Gig, submit the result through AGENCIE so it can move to review.

The submission keeps the completed work connected to the original assignment, assignee, deadline, and reviewer.

## Who Can Submit

The person assigned to the Gig can submit the work.

Having the same role as the assignee does not automatically allow another team member to submit on their behalf.

Assignment determines who currently owns the work.

## What To Include

A submission should contain:

- A written note
- An external link
- Or both

Use the submission to give the reviewer everything they need to evaluate the completed work.

## Examples

Depending on the assignment, you might submit:

- Google Doc link for scripts or copy
- Drive folder for footage
- Frame.io or Drive link for edited video
- Design file or preview link
- Published or scheduled content link
- Written output directly in the submission notes

AGENCIE stores the submission reference and workflow context. External files remain in the service where they are hosted.

## Good Submission Notes

Keep notes short but useful.

Instead of:

> Done.

Prefer:

> Completed all 5 scripts based on the campaign brief. Final Google Doc is attached through the link below.

For revision submissions, mention what changed:

> Updated scripts 2 and 4 based on the review feedback. Revised versions are available in the same document.

This gives the reviewer enough context without another conversation outside AGENCIE.

## What Happens Next

After submission:

Assigned
→ Work Completed
→ Submitted
→ Review

The Gig moves to the reviewer responsible for checking the work.

The reviewer can then approve the submission or request changes according to their available permissions.

## If Changes Are Requested

When the reviewer requests changes, responsibility returns to the assignee.

Review the feedback, update the work, and submit it again.

The cycle can continue until the work is approved.

## External Files

AGENCIE currently supports linking to externally hosted work rather than acting as the primary media-storage system.

Make sure the reviewer has permission to open any external link you submit.

A beautifully completed edit behind a `You need access` screen remains, from the reviewer's perspective, a philosophical concept.

> [!WARNING] Empty Submissions
> A submission should include notes, a link, or both. An empty submission does not provide the reviewer with anything to evaluate and should not be considered a valid handoff.
