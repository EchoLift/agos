## Who Can Submit

The assigned person can submit the gig.

## What To Include

Submit either a written note, an external link, or both.

Examples:

- Google Doc for scripts
- Drive folder for footage
- Frame.io or Drive link for edits
- Design file link

## What Happens Next

The gig moves to review and appears for the reviewer.

> [!WARNING] Empty Submissions
> A submission should include notes or a link. If the form allows an empty submission, treat it as a bug.
