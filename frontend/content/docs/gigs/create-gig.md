## How To Create

1. Open Gigs.
2. Choose New Gig.
3. Select client if relevant.
4. Choose gig type.
5. Add title and instructions.
6. Choose assignee and reviewer.
7. Set due date and priority.
8. Create the gig.

## Optional Fields

Estimated hours and reward are optional when configured as optional in the form.

## What Happens Next

The assignee receives the gig in My Work and Calendar. The reviewer receives review work after submission.
